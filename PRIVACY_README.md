# DD Compressor — Privacy Documentation

## Privacy-first design

DD Compressor is designed to process user-selected files locally on the device wherever supported by the app's implementation. The app is intended to avoid unnecessary uploading of personal files to an online compression server.

## What files can be accessed?

The app can access files that the user explicitly selects for compression. Selected files may contain personal or sensitive information, so users should only grant access and select files they want the app to process.

## Data collection

DD Compressor does not intentionally collect, sell, or rent the contents of user-selected files. The app is designed to minimize unnecessary collection and transfer of personal file data.

## Storage and saving

When a user saves or downloads a compressed file, DD Compressor may use the operating system's file-saving mechanism or the permission required for that operation. The user controls which files are selected and, where supported, where the resulting file is saved.

## Third-party services

The application is designed to minimize unnecessary third-party data transfer. Features or services that may affect data handling are documented in the application's current privacy policy.

## Android permissions

Permissions are requested only when required for file selection, processing, saving, or other relevant device operations. The app should not request unrelated permissions unnecessarily.

## Security

The project follows a privacy-first approach and aims to keep file processing local wherever supported. However, no software can guarantee absolute security. Users should keep their device and operating system updated and avoid selecting files they do not want the application to process.
